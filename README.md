# Домашнее задание 1: вёрстка и простой сервер

## Описание
Верстка страниц на Bootstrap + HTTP-сервер на Python.

## Как запустить
1. Запустить сервер: `python server.py`
2. Открыть в браузере: `http://localhost:8080`

## Страницы
- Главная (`index.html`)
- Категория (`category.html`)
- Каталог (`catalog.html`)
- Контакты (`contacts.html`) — главная страница сервера

## Дополнительно
- Обработка 404 ошибки (своя страница)
- POST-запрос из формы выводит данные в консоль

## Использованные технологии
- HTML, Bootstrap 5, Bootstrap Icons
- Python (http.server)
